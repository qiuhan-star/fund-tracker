怎么用？以后该给我（或填这里）什么数据？

方式一（最快，匹配你现在的截图）：在「持仓实时净值」表里，把基金 App 里的 基金名称 / 当前市值 / 持有收益率 抄过来。每天打开点「刷新」就能看动态。

方式二（推荐，能做单只复盘）：在「交易复盘」页的「交易流水」里，每买卖一次记一笔——日期、买/卖、金额、当时净值（App 里都能看到）。这样我能帮你复盘「这只买点好不好、该不该补/减」。

和我的配合：你可以直接把截图丢给我，我转成上面的数据；或者把导出的 JSON 发我，我帮你分析、给调仓方案。净值我工具会自动从天天基金拉，拉不到你手填一行即可。

数据怎么保证第二天还在？每次改表或刷新，数据会自动写进浏览器的 localStorage；用本机同一个浏览器打开同一文件，第二天数据都在。但 WorkBuddy 预览面板里填的是临时沙箱，关掉就没；清缓存或换浏览器也会丢。最稳妥两种方式：① 点「保存」会同时下载一份 fund-data-日期.json 存档，第二天用「导入」恢复；② 直接把数据发给我，我把真实数据写死进这个 HTML 文件，文件自带数据，永远不丢。

关于「实时」：这是本地文件，你每次双击打开点「刷新」即看到最新（需联网）。若想要每日自动推送，需要部署到云端，后续可以帮你做。
