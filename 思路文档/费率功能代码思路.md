# 费率功能代码思路（2026-08-16）

## 1. 两个核心概念区分（重要！）

### 1.1 持仓成本（平均成本法）
- **算法**：所有买入金额累加（不含赎回/分红/转换出），扣除卖出金额后除以剩余份额
- **公式**：`cost_per_share = (sum_buy_amount - sum_sell_amount) / remaining_shares`
- **用途**：计算"持有收益率"——已用了你项目里的支付宝一致算法
- **存储**：基于 trade 列表实时计算，不存储

### 1.2 持有天数（先进先出 FIFO）
- **算法**：每笔买入产生独立的一批份额，标记"买入日"；卖出时按最早一批先扣
- **数据**：每批份额有自己的 (date, shares, cost)
- **用途**：计算"赎回费"——平台按每批份额的持有天数决定费率
- **为什么不是平均成本**：支付宝的"持有 X 天免赎回费"指的是**单批**份额，不是整只基金。如果按平均成本算，你 2025-01-15 买的份额和 2026-08-10 买的份额合并后都说成"平均持有 200 天"，但 2026-08-10 那批实际只持有 5 天，卖出还是要扣 1.5% 赎回费。

### 1.3 关键区分
- **持仓成本 → 平均成本**（看的是"我平均每份花了多少钱"）
- **持有天数 → 先进先出**（看的是"我最早买入的那批份额持有了多久"）
- 这两个**绝对不能混**。

## 2. 费率规则模型

### 2.1 数据结构（每只基金独立）
```js
ftFundFeeRules = {
  "易方达蓝筹精选": {
    applyRate: 0.15,   // 申购费率 (%)
    sellSteps: [
      { days: 7, rate: 1.5 },    // 持有 < 7 天
      { days: 30, rate: 0.5 },   // 持有 7-30 天
      { days: Infinity, rate: 0 } // 持有 ≥ 30 天
    ]
  }
}
```

### 2.2 默认模板（按基金类型）
- **股票型 / 混合型**：0.15% 申购；7 天 1.5%，30 天 0.5%，30+ 免
- **债券型**：0.06% 申购；7 天 1.5%，30 天 0.1%，30+ 免
- **货币型**：0 申购；免赎回
- **黄金 / QDII**：0.15% 申购；7 天 1.5%，365 天 0.5%，365+ 免
- **指数 ETF / 联接**：0.10% 申购；7 天 1.5%，30 天 0.5%，30+ 免
- **FOF**：0.15% 申购；7 天 1.5%，30 天 0.5%，30+ 免

新增基金时按 `f.cat` 自动套默认模板，用户可在费率说明卡片里"编辑"修改。

## 7. FIFO 核心计算函数

```js
function computeFifoBatches(name) {
  // 返回 [{date, remaining_shares, cost_per_share}, ...] 按时间正序
  const trs = trades.filter(t => t.name === name)
    .filter(t => t.confirm !== 'cancelled')
    .sort((a,b) => (a.date+a.time).localeCompare(b.date+b.time));
  const batches = [];
  for (const t of trs) {
    if (t.type === 'buy' || t.type === 'dca' || t.type === 'activity' || t.type === 'reinvest' || t.type === 'convert') {
      // 买入：新批次
      const shares = t.shares || ((t.amount - (t.fee||0)) / (t.nav || 1));
      batches.push({ date: t.date, remaining: shares, cost: t.nav });
    } else if (t.type === 'sell' || t.type === 'convert_out') {
      // 卖出：从最早批次扣
      let need = t.shares || 0;
      for (const b of batches) {
        if (need <= 0) break;
        const take = Math.min(b.remaining, need);
        b.remaining -= take;
        need -= take;
      }
    }
  }
  return batches.filter(b => b.remaining > 0.001);
}

function earliestBatchDays(name) {
  const bs = computeFifoBatches(name);
  if (!bs.length) return null;
  const earliest = bs[0]; // FIFO 最早一批
  return daysBetween(earliest.date, today);
}

function computeRedemptionFee(name, sellShares) {
  const rule = getFeeRule(name);
  const bs = computeFifoBatches(name);
  const days = earliestBatchDays(name);
  const step = rule.sellSteps.find(s => days < s.days) || rule.sellSteps[rule.sellSteps.length-1];
  const currentNav = navCache[name]?.nav || 0;
  return sellShares * currentNav * step.rate / 100;
}
```

## 10. 风险与权衡

- **风险 1**：FIFO 计算需要遍历 trades，详情页打开 + 列表渲染 + 卖出输入会多次调用 → 在 trades 变化时缓存 `fifoCache[name] = {batches, days}` 避免重复计算
- **风险 2**：默认模板不准确 → 用户可编辑覆盖，编辑过的优先
- **风险 3**：QDII 基金的 T+1/T+2 净值延迟 → 卖出时用 `liveNav` 估值可能跟实际成交净值有 1-2% 误差 → 提示用文字说明"按当前估值估算"
